# 完整5轮同类候选 BadGraph 数据

本目录保存停止补跑后汇总的 **15,364条**完整样本：NC 7,710、LC 2,490、LP 5,164。目录名中的15785是原计划样本池大小，当前还差421条；未完成样本不收入本目录。

来源：原Luna批次14,756条，之前500条实验500条，Luna首批100条中完整的95条，以及此次hezubus GPT-6.1-sol补跑完整的13条。补跑任务已停止。

候选来自同一数据集：先选择与目标文本语义最远的可行类别，再从该类别选最不相似的候选。NC/LP使用母图节点类别；WN18RR的LC使用冻结的32个语义聚类。LC/LP对目标边两个端点分别应用类别约束，两个端点的类别可能不同。LC/LP保护目标边。关键词词面不匹配记录并继续，不启用Qwen复核。

- `train_rl.parquet`、`train_rl.jsonl`：与完整样本一一对应的攻击前clean数据，各15,364条。
- `budget1`至`budget5`：累计攻击1至5轮后的Parquet和metadata JSONL，每份各15,364条。
- `sample_results/{sample_id}.json`：对应样本的完整5轮数据和元信息。
- `manifest.json`：样本ID、任务数量、来源和排除列表。
- `provenance.jsonl`：原始结果文件的来源路径，仅用于追溯。
- `stop_summary.json`：停止与汇总记录。

已检查sample_id唯一，clean、五份budget和逐样本文件的ID集合一致；每个budget含对应数量的成功轮次、文本修改和新增边。攻击完整不表示受害模型一定预测错误。
